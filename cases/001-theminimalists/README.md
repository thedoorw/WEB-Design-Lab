# Case 001 — The Minimalists

REFERENCE = https://www.theminimalists.com/
TYPE = architecture / interaction reproduction
STATUS = STARTED

## Purpose

Use an existing mature editorial site as a pattern rather than redesigning from scratch.

Target transferable grammar:
- narrow centered shell;
- editorial stream;
- title/excerpt/detail continuation;
- long-form reading page;
- archive/pagination;
- resource/index page;
- responsive navigation;
- footer rhythm.

## Content substitution

Source copy, photography, logos and identity assets are not production assets.

The reconstruction should use neutral placeholders until a formal Site Repo receives its own content.
